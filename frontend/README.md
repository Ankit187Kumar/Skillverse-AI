# SkillVerse AI — frontend

Next.js 16 (App Router) + TypeScript + Tailwind CSS 4 + Framer Motion + Lucide.

```bash
npm install
npm run dev        # http://localhost:3000, proxies /api/* to BACKEND_URL (default http://127.0.0.1:8000)
npm run lint
npm run build && npm start
```

See the main README in the repository root for full setup, configuration and deployment.
